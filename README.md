 **Simple Vulnerability Scanner**

A beginner-friendly Python-based vulnerability scanner that detects open ports, running services, and their versions on a given IP address or domain.  
It also saves a detailed scan report into a .txt file.

---
**Features**
- Scan a target IP address or domain for open ports.
- Detect services, products, and versions.
- Save results automatically in a text report.
- Easy command-line interface for beginners.
- (Optional) Print report contents after scan.

---

**Technologies Used**
- Python 3
- Nmap(Network Mapper)
- python-nmap library
